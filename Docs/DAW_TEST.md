# DAW visual/functional QA

After build and install:

1. Load BB Tube Compressor on a stereo track.
2. Play audio and verify IN/GR/OUT meters move.
3. Change Threshold and verify the compression curve changes.
4. Change Ratio and verify the curve changes.
5. Toggle Stereo Link and verify left/right balance behavior changes.
6. Change Tube Drive/Harmonics and monitor the output level and waveform/spectrum.
7. Toggle Limiter and verify the ceiling clamp reacts to peaks.
8. Switch Peak/RMS and verify detector response changes.
9. Switch Stereo / Mono / Mid-Side / Dual Mono.
10. Select each factory preset and verify all attached controls update.
11. Save host state, close/reopen the project, and verify recall.
12. Test offline bounce/render.
